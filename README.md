# Landing Page

This is a [Landing Page](https://www.theodinproject.com/lessons/foundations-landing-page) exercise project from [The Odin Project](https://www.theodinproject.com/).

The main goal of this project was to practice using CSS Flexbox and build a complete webpage from scratch.

The theme for the project was optional, and I chose to create a NatureTraveler landing page inspired by travel, nature, and outdoor adventures.
